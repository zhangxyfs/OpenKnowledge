OpenKnowledge 的版本发布记录。日期为 2026 年。

v2.12.0

最新2026-08-12
新功能
  • 新增 codex 适配器（第七个 AI 助手集成）：合并写 ~/.codex/hooks.json（备份 + 幂等 + 第三方条目保留），hook 契约逐字兼容 Claude Code（注入 hookSpecificOutput.additionalContext、Stop decision:block），输出协议零改动复用；写盘追踪解析 apply_patch 补丁头（*** Add File: 等四标记），auto 自省与 enforce 规则与 Claude 同档；技能零适配——Codex 原生扫描共享 ~/.agents/skills；注意 Codex 信任门：安装后首次运行会提示信任 hooks（/hooks 管理）

v2.11.1

2026-08-12
新功能
  • 新增 claude 生态适配器（第六个 AI 助手集成）：合并写 ~/.claude/settings.json 的 hooks（备份 + 幂等 + 第三方条目保留），Claude Code 与 CodePilot 等 claude-agent-sdk 兼容宿主共享此文件，装一次多宿主生效；CodePilot 实测 UserPromptSubmit/Stop 均原生执行（agent 内核 settingSources 含 user 层，shadow HOME 只剥 ANTHROPIC_* env 键）；技能目录 ~/.claude/skills
改进
  • 修复：registry.Home() 对环境变量重定向免疫（Windows 走 SHGetKnownFolderPath 真实配置目录，其他平台 os/user 解析）——CodePilot 等宿主以 DB provider 运行时把子进程 HOME/USERPROFILE 重定向到 shadow 临时目录做隔离，旧实现跟随重定向会看到空数据根，hook 注入静默失效且无任何日志痕迹（显式覆盖口不变：OK_HOME 环境变量仍第一优先）

v2.11.0

2026-08-12
新功能
  • 新增 opencode 适配器（第五个 AI 助手集成）：ok setup / GUI 引导页一键安装全局 TypeScript 插件（~/.config/opencode/plugins/openknowledge.ts）——提问时检索注入（synthetic part，不占用界面消息位）、写盘追踪覆盖 write/edit 与 apply_patch（gpt 系模型）、回合空闲时经 SDK 补发沉淀提醒（stop 闭环）；幂等安装、过期自愈、卸载干净
改进
  • 「未检测到支持的 agent」提示与 ok doctor 名单改为动态列举；setup 与引导页「下一步」文案不再写死 kimi
说明
  • 技能零适配：opencode 原生扫描共享目录 ~/.agents/skills；opencode 无 hooks 配置字段，集成形态为插件 hooks（与 pi 同构）

v2.10.1

2026-08-10
修复
  • 导出/导入纳入 wiki 状态：state/wiki.json（基准分支 + 按分支游标 + 合并谱系）随 zip 包备份，导入时原样还原。此前导出范围只有条目与 config——删除项目知识库的「导出 zip 备份」不含谱系，重导入后 GUI 谱系行归零、wiki 游标丢失导致全量重扫
说明
  • 旧备份包无 wiki.json 时跳过还原，向后兼容；条目索引仍在导入时自动重建

v2.10.0

2026-08-09
新功能
  • 新增 Linux 发布线（amd64）：.tar.gz（解压即用）与 .deb（装到 /usr/lib/openknowledge/，ok 进 PATH）
  • Linux 桌面体验补齐：ok gui 经 xdg-open 打开默认浏览器；ok setup 自动写入 XDG 登录自启，卸载时移除
说明
  • Windows 行为零变化；Linux 二进制纯静态编译（无 CGO），发行版通吃

v2.9.0

2026-08-09
新功能
  • 其他页新增「删除项目知识库」：永久删除所选项目的全部知识、索引与配置，并注销注册表（hooks 不再注入该项目）；项目源码目录不受影响
  • 多重确认防误删：影响面明示 → 删除前导出 zip 备份（默认勾选）→「我已了解后果」勾选 + 输入完整项目名双重解锁
  • 后端先注销注册表再删目录：任一步失败都偏向「保留数据」
修复
  • 删除当前选中项目后不再误弹「项目未注册」错误横幅

v2.8.2

2026-08-09
改进
  • 项目下拉按最近知识更新排序：最近有写入的项目排最前，打开 GUI 默认即选中
  • 刷新按钮改全量刷新：项目列表、状态、条目一次拉齐；带「刷新中… → 已刷新 ✓」反馈，防重复点击

v2.8.1

2026-08-09
改进
  • GUI 管理页表头中文化：tags → 标签，mandatory → 必注入（悬停保留原字段说明）
  • 摘要列最多显示 2 行、超出省略号；悬停浮窗显示完整内容（跟随鼠标、溢出自动翻转、滚动即收起）
  • 管理页每页条数 20 → 12，信息密度更适中

v2.8.0

2026-08-09
新功能
  • 条目级分支溯源（provenance）：每条新知识自动记录出生分支（born 标签），GUI 分支列展示「⎇ 出生分支」徽标；ok backfill-born 可回填存量
  • 合并谱系落盘：分支并入基准自动记录，GUI 显示「dev → master」
  • GUI 分支上下文：工具条显示「基准分支 · 当前分支」，不一致时警示
说明
  • born 与 branch 标签正交：branch 管「在哪生效」（注入过滤），born 管「在哪出生」（展示）；零迁移，旧知识库开箱即用

v2.7.1

2026-08-08
新功能

  • GUI 条目类型显示中文化（规则/踩坑/笔记/参考；存储值仍为英文）

v2.7.0

2026-08-08
新功能
  • wiki 分支差异条目：长期并行分支只维护与基准分支的结构差异，注入按当前分支过滤，他分支差异不再误导 agent
  • 分支合并感知：dev 并入 master 后提示清理失效差异条目（每会话一次）
  • GUI 管理页：分支列 + 分支过滤器 + 操作列固定
修复
  • 非基准分支跑 wiki 更新不再污染全量条目（技能流程改为只写差异条目）
  • prompt 热路径 git 调用收敛，每次提问少 1-2 次 git 子进程
  • ok wiki mark 对用户传入 rev 先 rev-parse 归一化，修短 hash 游标误判 diverged

v2.6.0

2026-08-08

  • 游标被 rebase/squash 改写后显式提示「游标失效」
  • ok wiki base 查看/设置基准分支；ok wiki status 输出 branch/base_branch/branch_state

v2.5.0

  • 强制检查三档开关（仅 Reasonix）：mixed / soft / hard，GUI 引导页可配，保存即时生效
