v2.17.0

最新2026-08-16
新功能
  • 泛化 prompt 门控：「继续」「好的」「ok」这类无信息量 prompt 不再跑检索——连 embedding 网络往返都省掉；内置 21 条中英常用确认词（随版本演进），GUI 引导页新增「泛化门控」卡片 + 短语管理弹窗可维护自定义短语（与内置取并集、自动去重，单条 ≤64 字符）；mandatory/索引/wiki 提醒等其余注入不受影响
  • 时效信号：按条目文件 mtime 的新鲜度给检索分乘系数——新鲜窗口内 1.0、陈旧后 0.85、中间线性，窗口按条目类型分（pitfall 90/365 天、note 60/180、rule/reference 180/730）；不参与准入，只在近似同分时让位；编辑条目即刷新新鲜度
  • 注入→采纳反馈闭环：新增 entry_events 表记录「注入/采纳」事件——采纳 = 本会话注入过的条目被读取（post-tool 不开库，先挂账会话状态、下次 prompt 入账）；30 天窗口内注入 ≥4 次且零采纳的条目降权 ×0.8（v1 只降不升）
改进
  • 检索融合改 RRF（Reciprocal Rank Fusion，按名次不按分数）：换 embedding 模型后余弦分布漂移不再破坏两路平衡；双通道同时命中的条目天然「交叉验证优先」；准入逻辑不变；ok search 分数输出改 4 位小数
说明
  • 反馈降权默认关闭（retrieve.feedback.enabled = false）：现行所有宿主的 PostTool 钩子只派发写工具，read 不到达追踪链路，采纳信号暂恒为零，开启会误伤频繁注入的条目；注入/采纳事件照常记录，待 read 派发接通后的版本恢复默认开启
  • 要旧排序行为可在配置里显式 fusion = "weighted"（旧 α/β 加权回滚档）；时效与门控均可经 retrieve.recency.enabled / retrieve.gate.enabled 单独关闭

v2.16.2

2026-08-15
新功能
  • 日志全行时间戳：daemon.log（含 http.Server 内部错误）与 embed-sidecar.log（llama-server 输出）按行加时间戳，后者新增启动/退出分隔标记——多次启动的日志交织后也能对上时间线
改进
  • 落盘写入统一原子化（同目录临时文件 + fsync + rename）：INDEX.md、registry.toml、config.toml、各宿主 settings、备份导入、知识条目、wiki 游标——崩溃/断电不再留半截文件，宿主也不会读到截断的 JSON
  • 注入预算按密度估算：中文按约 1 token/字、拉丁按约 4 字符/token（旧实现统一 2 字符/token，对中文为主的条目低估约 2 倍）；max_tokens 误配为负数不再崩溃
修复
  • 修复会话状态并发竞态：并行工具调用派发的多个 hook 进程对同一会话状态无锁读改写，互相覆盖丢 Touched（changelog 规则漏拦）、极端时 BaseInjected 归零导致 mandatory 全文重复注入——新增跨进程锁 + 锁内合并 + 原子落盘
  • 修复强负余弦把已过关键词门槛的命中挤出注入（语义通道不应有单方面否决权，语义分只影响排序）
  • 修复 top_n 截断先于分支过滤导致的注入欠额：其他分支条目被过滤后本分支条目无补位
  • 修复 kimi hook 命令路径含空格时静默失效（exe 补引号，存量配置照常自愈替换）；修复版本同步脚本 winres 段 sed 分隔符冲突导致同步中断
说明
  • 本版为稳健性批次：注入机制无行为变化，主要修复并发与边界条件缺陷；升级安装器会先自动停止旧 daemon，日志时间戳自新 daemon 拉起后生效

v2.16.0

2026-08-15
新功能
  • 检索注入按通道独立准入：总分只用于排序，关键词通道归一 BM25 分 ≥ 阈值 或 语义通道余弦 ≥ 语义门槛才注入——宁缺毋滥、不再强行凑 top_n；新增 retrieve.min_score（默认 0.5，≤0 关闭），阈值随库规模缩放（<10 条关闭、10→30 线性、≥30 取全值）
  • 语义门槛模型无关（SemanticFloor）：以本次查询余弦分布为参照，头部相对中位数有显著分离（retrieve.min_gap 默认 0.25，可配）才启用 median+0.5·gap，无头部则语义通道整体不准入；四模型 12 场景标定（bge-m3 / bge-large-zh-v1.5 / Qwen3-Embedding-8B / qwen3-emb-0.6b）
  • GUI 第四标签「日志」页：GET /api/logs 回读 ok / 守护 / embedding 三来源日志尾部，2 秒轮询实时刷新，来源 chips 多选 +「仅语义」开关 + 文本过滤输入框，上滚暂停自动贴底
  • 语义诊断可见化：语义通道全部候选被拒时写 prompt semantic 日志（样本数/max/median/relGap），ok search 同步提示调节指引；语义检索退化（模型身份缺失/切换）时注入末尾每会话一次附提示
改进
  • 发布流程加固：scripts/sync-version.sh 现在同步 cmd/ok/winres.json 的 exe 版本资源（此前 bump 时易漏，v2.9.0 起一直漂移停在 2.8.0.0）
修复
  • 修复注入知识与提问无关：CJK 二元组伪词（如"已经验证"切出"经验"）命中标题即可注入、同域语料下无关文本的余弦基线（实测 bge-m3 跨域噪声高达 0.52）顶穿总分阈值——准入改按通道独立判定后，无关提问零注入、相关提问精确命中
  • 修复 exe 文件版本资源自 v2.9.0 起漂移停在 2.8.0.0 的问题
说明
  • 切换 embedding 模型后必须 ok index 重建向量（身份守卫会拦旧向量）；低对比度自定义模型可调低 min_gap（必要时配合 min_score）放宽语义准入；极端低对比度下语义通道整体静默关闭（fail-closed，关键词通道兜底），GUI 日志页「仅语义」可观察诊断行
