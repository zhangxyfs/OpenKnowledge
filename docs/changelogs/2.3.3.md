# 2.3.3

## 新功能
- 升级后打开 GUI 自动弹出更新日志：changelogs 随安装包分发到 `{app}/changelogs/`，跳级升级累计展示所有新版本（如 2.3.0 → 2.3.3 依次展示）；"其他"标签页新增"更新日志"常驻入口，随时回看全部历史版本
- 新 API：`GET /api/changelog`（当前版本/未看版本/全部历史）、`POST /api/changelog/seen`（已看状态存 `~/.openknowledge/gui.json`；首次运行、dev 构建、降级安装均不弹窗）

## 修复
- 仅升级弹窗的"知道了"才标记已看——常驻入口查看不影响已看状态（避免拉取失败时升级提醒被永久吞掉）
