# 2.2.3

## 新功能
- 系统托盘：daemon 运行时右下角显示图标；单击弹菜单（版本号 + 退出），双击打开/聚焦唯一 GUI 窗口（ZeroTier 风格菜单）

## 修复
- hook 调用不再闪 cmd 黑窗口（procx.HideWindow / CREATE_NO_WINDOW，git/powershell/cmd 子进程静默化）
- GUI 最大化只作用于本次新开的窗口（旧 token 残留窗口不再抢命中）
- 安装器在文件拷贝前自动 daemon stop，避免 hooks 拉起的 daemon 锁住 ok.exe 导致升级失败

## 优化
- hook 注入瘦身：INDEX 主列表不再重复 wiki 条目；默认预算 1500→800、top_n 3→2；检索命中注摘要+文件路径而非全文（mandatory 条目仍全文）
