# v2.16.1 mandatory 注入健壮性 + 压缩重注入 + Claude PreCompact

> 核心变化：mandatory 条目不再因长索引/上下文压缩而失效——每轮粘性指针、永不被截断、
> 压缩后重注入；Claude Code/CodePilot 接入 PreCompact；修复 go test 污染真实 DSH 插件的测试隔离漏洞。

- **mandatory 注入健壮性（L3/L4/L2）**：
  - 粘性指针（L3）：首轮注入全文后，后续每轮仅注入「标题 + 文件路径」一行指针
    （几十 token），即使宿主压缩上下文把首轮全文摘要掉/沉入 lost-middle，模型仍能据此重读原文；
  - 永不被截断（L4）：mandatory 段与「INDEX + 检索」段分离构建，预算截断只作用于非
    mandatory 部分——旧实现单 builder 砍头，长 INDEX/检索会把尾部 mandatory 静默砍掉；
  - 压缩重注入（L2）：Reasonix 接入 `compaction.complete`、Claude Code/CodePilot 接入
    `PreCompact`，压缩前重置基础注入标记，压缩后下一次提问即重注入全文；
  - 通用兜底：新增 `[inject] reinject_turns`（默认 0=关闭），无显式压缩事件的宿主
    （ZCode/Codex/Kimi/Qoder/Qoder-IDE/DSH/OpenCode/Pi）按轮次周期性重注入全文。
- **测试隔离修复**：hook / rxext 两包 TestMain 补 `OK_DSH_HOME` 隔离——此前 `go test`
  会经 `selfHealHooks` 用测试二进制（`hook.test.exe`）覆盖真实 `~/.dsh` 插件，
  导致 DSH 注入静默失效（与"混合检索"无关，症状易误判为检索回归）。
- **测试**：新增 TestMandatoryPointerAfterBase / TestMandatoryNeverTruncated /
  TestReinjectTurnsPeriodic / TestHandleCompactResetsBaseInjection /
  TestCompactionResetsBaseInjected；全仓 `go test ./internal/...` 绿。
