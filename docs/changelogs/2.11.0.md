# 2.11.0

## 新功能
- 新增 opencode 适配器（第五个 AI 助手集成）：`ok setup` / GUI 引导页一键安装全局
  TypeScript 插件（`~/.config/opencode/plugins/openknowledge.ts`）——提问时检索注入
  （synthetic part，不在界面占用消息位）、写盘追踪覆盖 write/edit 与 apply_patch
  （gpt 系模型只发 apply_patch，解析补丁内的文件标记行）、回合空闲时经 SDK 补发
  沉淀提醒（stop 闭环，与 pi 同构）；幂等安装、过期自愈、卸载干净

## 改进
- 「未检测到支持的 agent」提示与 `ok doctor` 名单改为动态列举（随注册表自动更新）
- setup 与 GUI 引导页「下一步」文案泛化，不再写死 kimi

## 说明
- 技能零适配：opencode 原生扫描共享目录 `~/.agents/skills`
- opencode 没有 hooks 配置字段，集成形态为插件 hooks（与 pi 同构），配置根遵循
  `OPENCODE_CONFIG_DIR` / `XDG_CONFIG_HOME` 约定
- 插件子进程走 `node:child_process`，CLI/TUI（Bun）与桌面端（Electron/Node）双运行时兼容
