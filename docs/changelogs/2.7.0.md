# 2.7.0

## 新功能
- wiki 分支差异条目：长期并行分支只维护与基准分支的结构差异（`ok wiki diff` 供素材 + openknowledge-wiki 技能差异流程），注入按当前分支过滤（含 INDEX.md 分支差异小节裁剪，分支未知不过滤），他分支差异不再误导 agent
- 分支合并感知：dev 并入 master 后 `ok wiki status` 报 merged_branches，prompt 注入提示清理失效差异条目（每会话一次）
- GUI 管理页：分支列（时间后）+ 分支过滤器（随项目联动）+ 操作列固定（长分支名横滑可用）

## 修复
- 非基准分支跑 wiki 更新不再污染全量条目（技能流程改为只写差异条目，写侧防呆）
- prompt 热路径 git 调用收敛（CheckStatus 改 merge-base 判别，每次提问少 1-2 次 git 子进程）
- `ok wiki mark` 对用户传入 rev 先 rev-parse 归一化——修短 hash 游标误判 diverged

## 说明
- 无 `branch:` 标签条目的项目行为与旧版完全一致
