# v2.18.1 修复批次：GUI 编辑保生命周期标记、mandatory 过滤归档、Sync 全线透传 max_lines

> 全仓代码审查（`docs/2026-08-17-bug-review.md`）确认的九处问题一次修完，
> 每处附回归测试。均为逻辑缺口，无接口变化，直接升级即可。

## 修复

- **GUI 编辑草稿/归档条目丢标记**：管理页编辑一条草稿保存后会被静默转正（未经
  采纳流程直接参与注入），编辑归档条目会被静默取消归档。更新路径现从盘上旧
  条目继承 `draft`/`archived`/`created`，编辑器只管内容不管生命周期。
- **归档的 mandatory 条目仍被强制注入**：归档一条过时规则后它从 INDEX 消失，
  却仍每会话全文注入。mandatory 查询现已过滤归档——归档语义统一为"退出一切
  强制暴露、仍可被检索命中"。
- **GUI 与备份导入覆盖 max_lines 配置**：配置了 `[index] max_lines` 后，GUI 里
  任何条目增删改/采纳、或导入备份，曾把 INDEX.md 按默认值 50 重渲染。现在
  全线按项目配置透传。
- **缺向量的损坏条目中止整轮同步**：模型切换或新配 embedding 后的向量补齐阶段，
  一个损坏文件曾导致 `ok index` 持续失败。现与变更路径同口径：跳过该文件并
  告警，其余条目照常同步。
- **wiki 标签子串误判**：标签 `sewiki`/`nowiki` 曾被当作 wiki 条目处理；各处
  判定改为整标签精确匹配，wiki 计数与 Wiki 目录口径统一（均不含归档条目）。
- **小项**：`ok add --force` 与 GUI 保存补同秒写入的 mtime 推进（防索引漏更）；
  `ok archive` 改原子写（防断电留半截文件）；`ok doctor` 对手工编辑产生的
  无路径项目不再崩溃；备份导入空路径项目不再写入假空串路径。
