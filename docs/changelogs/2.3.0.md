# 2.3.0

## 新功能
- 多 Agent 支持：新增 Pi 集成（`~/.pi/agent/extensions/` TS 扩展注入 hook），与 Kimi Code 并列；`internal/agentx` 适配器注册表，后续 agent 一个文件即可接入
- GUI 引导页新增 agents 下拉菜单：hooks 配置卡随选中 agent 联动（徽标/按钮/安装目标），选择持久化；未安装 agent 置灰标注
- `ok setup --agent <id>`：只安装指定 agent 的 hooks；缺省对全部已检测 agent 一键安装
- `/api/status` 返回 agents 数组（id/name/detected/hooksInstalled）；`POST /api/setup/hooks` 支持 `{"agent": "<id>"}`

## 修复
- hook 安装/卸载改为收集式错误聚合：单个 agent 失败不影响其他 agent，最后汇总报告
- 技能状态检测漏检 wiki 技能（5 → 6 个，按注册表动态检查）
- `ok setup --agent` 不再误跳过 embedding 交互配置
