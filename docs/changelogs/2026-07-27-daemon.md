# 常驻 daemon（单进程架构）

- **问题**：任务管理器常见多个 ok.exe——GUI 无单实例且浏览器打开失败时看门狗永不上膛（真泄漏）；
  kimi 每会话每提问各起一个 hook 进程，embedding 同步无总时长上限；kb.log 出现 SQLITE_BUSY。
- **方案**：唯一常驻 ok.exe daemon 承载 GUI 与 hook 请求：
  - 新增 internal/daemonx（daemon.json 凭证 + 健康/版本检查）与 internal/daemon（mux/Run/spawn/转发）；
  - 端口 17888 即单实例锁；exe 指纹不一致自动换新版；hook 瘦客户端 9s 转发，daemon 不在则本地兜底+后台拉起；
  - GUI 取消 30s 看门狗（daemon 常驻，关页面不退出）；ok gui 开浏览器即退；
  - 安装器 HKCU Run 登录自启，卸载先停 daemon；setupx.Uninstall 同步停 daemon；
  - index.Open 加 busy_timeout(3000)，兜底 daemon 与本地路径的短暂并发写。
- **兼容**：daemon 完全不可用时行为与旧版一致（本地处理、fail-open）；CLI 命令保持本地执行不转发。
