# v2.0 Web GUI：图形化管理 + 首次引导 + dist 发布构建

- **setupx 重构**：`ok setup` 的 hooks 写入、技能安装、embedding 配置/连通性验证、
  全局开关逻辑下沉为独立 `internal/setupx` 包，供 CLI 与 GUI 两个入口复用。
- **gui 服务（`internal/gui`）**：新增 `ok gui` 子命令；无参数运行（双击 exe）同效。
  127.0.0.1 随机端口 HTTP 服务，16 字节随机令牌鉴权（`X-Ok-Token` 头，令牌注入
  index.html 的 `{{TOKEN}}` 占位符），自动打开浏览器；页面每 5s 心跳，30s 无心跳
  自动停服，`POST /api/shutdown` 立即停服。web 资源从 `<exe目录>/web` 或
  `<当前目录>/web` 加载。
- **管理 API**：`/api/status` `/api/projects` `/api/entries` `/api/entry`
  （GET/POST/PUT/DELETE）`/api/search` `/api/toggle` `/api/setup/hooks`
  `/api/setup/skills` `/api/setup/embedding` `/api/heartbeat` `/api/shutdown`。
  写操作自动同步索引库；条目文件名参数做路径穿越校验。
- **双标签页前端（`web/`）**：零依赖原生 HTML/JS/CSS。「管理」页提供项目/条目
  列表、新建/编辑/删除、检索预览（命中高亮）、全局开关；「引导」页一键完成
  hooks 配置、技能安装、embedding 配置。hooks 未安装时「管理」页自动隐藏。
- **dist 发布构建**：新增 `scripts/build-dist.sh`，以 `-ldflags "-s -w"` 构建
  `dist/ok.exe` 并拷贝 `web/` 为 `dist/web/`，即开箱即用的发布目录。
