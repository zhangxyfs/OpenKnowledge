# v2.18.2 GUI 归档入口 + 全局配置并发加固

> 全仓审查第二/三轮（`docs/2026-08-17-bug-review.md` #11-#19）的修复与功能补全，
> 每处附回归测试。无接口破坏，直接升级即可。

## 新功能

- **GUI 归档入口**：管理页条目行新增「归档/恢复」按钮与归档徽标（归档行淡显）。
  归档条目退出 INDEX 主列表、Wiki 目录与 mandatory 强制注入，仍可被关键词/
  向量检索命中——给知识库瘦身不用再开终端跑 `ok archive`。

## 修复

- **全局配置并发写丢更新**：GUI 里同时保存 embedding profile、切换使用中服务、
  改 hooks 超时等操作曾互相覆盖（后写者赢），且写盘非原子、崩溃会留半截
  config.toml 导致全线报错。现所有配置保存走跨进程文件锁内读-改-写 + 原子
  落盘。
- **embedding 零超时挂死**：`timeout_sec` 显式配 0 时查询路径曾无任何超时
  （http 零值=永不超时），`ok search`/`ok doctor` 可长时间卡死。现钳回默认
  5 秒。
- **daemon 重启后误杀风险**：内置模型 sidecar 的跨进程停杀曾只凭状态文件里的
  PID——sidecar 已死且 Windows 复用该 PID 时会误杀无关进程。现杀前先探测
  服务健康，不应答则只清状态文件。
- **wiki 旧格式游标无提示**：游标 commit 被历史改写后此前静默归入"git 不可判"、
  落后提醒永不触发，现正确报 `legacy_orphan`。
- **小文件写非原子统一**：各 agent 的 TS/JS 插件、manifest、SKILL.md、Linux
  自启 desktop 文件等改写原子写（与主配置文件同标准）。

## 说明

- 全局配置保存仍是整档重写：手写进 config.toml 的**注释与未识别键不会保留**
  （配置由 GUI/CLI 托管，此为已声明取舍；要保注释请改完别再用 GUI 保存）。
- 发布脚本：GitHub 产物列举改用正确的 `per_page` 分页参数（原 `limit` 仅
  Gitea 认；产物少于一页时本就不影响，顺手修正）。
