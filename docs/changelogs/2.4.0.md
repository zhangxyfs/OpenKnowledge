# 2.4.0

## 新功能
- 多 Agent 支持新增 ZCode 集成：`internal/agentx` 第三个适配器，hook 配置合并写 `~/.zcode/cli/config.json`（`hooks.events` 三事件、`type:"process"` 直 exec、统一 `timeoutMs`），保留用户未知字段与自有 hook，写前备份 `.bak-openknowledge`
- hook 输出新增 Claude/ZCode JSON 协议格式（`ok hook <event> claude`）：prompt 注入包成 `hookSpecificOutput.additionalContext`，Stop 阻断走 stdout `decision:block` + exit 0；daemon 转发经 `?format=` 透传；kimi/pi 的纯文本/stderr+exit 2 语义不变
- 技能分发启用每 agent 独立目录：ZCode 技能装到 `~/.zcode/skills`（ZCode 不自动读 `~/.agents/skills`）；`InstallSkills` 写所有已检测 agent 的技能目录并集，卸载按全部注册 agent 并集清理，GUI 技能状态检测同步按并集
- `ok doctor` 改为逐 agent 报告 hooks 安装状态（不再只查 kimi）

## 说明
- ZCode 侧生效方式：安装本版本后运行 `ok setup --agent zcode`（或在 GUI 引导页选 ZCode 点安装），**新建 ZCode session** 后 hooks 生效（ZCode 在 session 启动时快照 hook 配置）
