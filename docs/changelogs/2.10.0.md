# 2.10.0

## 新功能
- 新增 Linux 发布线（amd64）：`openknowledge_<版本>_linux_amd64.tar.gz`（解压即用）
  与 `openknowledge_<版本>_amd64.deb`（装到 /usr/lib/openknowledge/，ok 进 PATH）
- Linux 桌面体验补齐：`ok gui` 经 xdg-open 打开默认浏览器；
  `ok setup` 自动写入 XDG 登录自启（~/.config/autostart/），卸载时移除

## 说明
- Windows 行为零变化；Linux 二进制纯静态编译（无 CGO），发行版通吃
- .deb 经 nfpm 构建；构建入口 `bash scripts/build-linux.sh`
