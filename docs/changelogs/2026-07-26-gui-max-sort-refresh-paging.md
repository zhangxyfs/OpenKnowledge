# GUI：默认最大化、时间排序切换、自动刷新、分页

- **默认最大化**：浏览器应用模式启动加 `--start-maximized`（Edge/Chrome）。
- **时间排序切换**：时间列头可点击切换正序/倒序，带 ↑/↓ 箭头指示。
- **刷新与自动刷新**：工具栏新增"刷新"按钮；心跳（5s）携带项目 kb.db 的
  mtime 作为版本号，前端发现版本变化才重拉列表（变更驱动的条件刷新，
  避免全量轮询）；手动刷新/切换项目会重置版本记录。
- **分页**：每页 20 条，底部显示"共 N 条 · 第 X / Y 页"与上一页/下一页按钮
  （自动禁用）；切换项目/类型过滤/搜索时回到第一页，页码越界自动收拢。
