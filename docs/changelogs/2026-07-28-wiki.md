# v2.2 项目 Wiki：游标跟踪 + Wiki 目录 + 落后提醒 + openknowledge-wiki 技能

- **`ok wiki status|mark`（`cli.WikiCmd`）**：`status` 以 JSON 输出
  `project/has_wiki/behind/stale/threshold`（`behind=-1` 表示 git 不可用）；
  `mark [commit]` 把 wiki 生成位置记到游标（缺省取 HEAD），并统计 wiki 条目数。
- **游标（`internal/wiki`，新叶子包）**：`state/wiki.json` 记录
  `last_commit/generated_at/entry_count`，固定文件名、不受 state 目录
  session-* 7 天 GC 影响；落后计数用 `git rev-list --count <cursor>..HEAD`，
  无游标时按全历史计，git 不可用 fail-open。
- **`[wiki] stale_commits` 配置**：落后多少 commit 触发提示，默认 20，
  0 = 关闭；三层配置合并（内置默认 ← 全局 ← 项目）。
- **INDEX.md Wiki 目录**：`index.Sync` 重建 INDEX.md 时追加「## Wiki 目录」
  一节，数据源为 `tags LIKE '%wiki%' AND draft=0`（按 title 排序，描述取
  summary），无 wiki 条目时省略该节（输出与之前逐字节一致）。
- **prompt hook 每会话一次 nudge**：每次提问在注入文本末尾检查，若 wiki 落后
  达阈值则追加提示（`session.WikiNudged` 记忆，同会话只提示一次）：从未生成时
  建议用 openknowledge-wiki 技能生成 wiki；已生成则提示「wiki 已落后 N 个
  commit」建议增量更新。非 git 项目/git 不可用静默。
- **openknowledge-wiki 技能（第 6 个技能）**：随 `ok setup`（或 GUI 引导页）安装，
  模板文件 `internal/setupx/skills/openknowledge-wiki/SKILL.md` 经 go:embed
  烧入 exe 路径；驱动 AI 扫描项目、以 `ok add --type reference --tags wiki`
  写 wiki 条目，最后 `ok wiki mark` 记录游标。
- **端到端测试**：`cmd/ok/wiki_test.go` 覆盖 init → status(behind=3) →
  add wiki 条目 → mark → INDEX.md Wiki 目录 → 追加 commit 后 status(behind=1)
  → 阈值降为 1 后 prompt nudge → 同会话不重复。
