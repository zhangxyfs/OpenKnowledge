# 2.5.0

## 新功能
- 多 Agent 支持新增 Reasonix 集成：`internal/agentx` 第四个适配器。Reasonix 的 UserPromptSubmit 不注入 stdout，故不走 settings.json hook，改为安装 Extension Protocol 插件包——`plugins/openknowledge/reasonix-plugin.json`（runtime.command 直指 ok.exe、`args=["extension-serve"]`、`required=false`，sidecar 崩溃宿主降级不阻断）+ `plugin-packages.json` 信任门登记（写前备份 + temp+rename 原子写）
- 新增 `ok extension-serve` sidecar 子命令（`internal/rxext`）：拦截 `input.receive`（逐 prompt 检索注入 + 强制检查三档分流，block 优先于注入）与 `tool.after`（写工具成功执行才记 touched）；注入/检查核心与 hook 子命令共用 `internal/hook/core.go`（`InjectForPrompt`/`TrackTouched`/`CheckStop`），与 kimi/pi/zcode 语义一致；SDK 为 `internal/rxext/sdk` vendor 快照
- 强制检查三档开关（仅 Reasonix）：全局配置 `[reasonix] enforce_mode` = `mixed`（默认，auto 自省软提醒 / 规则硬阻断）/ `soft`（全软提示）/ `hard`（全硬阻断）；GUI 引导页新增"强制检查方式"三档，保存即时生效（sidecar 每 prompt 读配置）；软路径把提醒与注入合并为一个 `<ok-context>` 块前缀进原输入
- Reasonix 技能目录共享 SkillsHome（`~/.agents/skills`），技能分发机制零改动；hook 入口自愈覆盖插件包（曾登记且内容过期才重写，从未登记不复活），卸载清理插件目录与信任门登记两点位

## 说明
- Reasonix 侧生效方式：安装本版本后运行 `ok setup --agent reasonix`（或在 GUI 引导页选 Reasonix 点安装），Reasonix 加载插件包后生效；会话内 `/reload` 可重生 sidecar
- sidecar 全面 fail-open：拦截器 panic/错误一律 Continue 不阻断输入，任何内部异常只记 ok.log
- `ok off` 全局开关对 reasonix sidecar 同样生效
