Codex 信任门与版本说明

① Codex 0.118 把 hooks 列为实验特性（默认关闭）：ok 安装时已自动在 ~/.codex/config.toml 开启并写入信任记录，无需手动确认信任；在 Codex 的 设置 → 编码 → 钩子 页面可随时查看或逐条关闭。
② Windows 下 hook 命令经 ok-hook-*.cmd 包装文件执行（规避 Codex 引号 bug），exe 迁移/升级后 ok 自愈不再失效。
③ 版本注意：桌面端 26.707 与命令行 codex 0.147+ 均已实证可用（更早版本未验证）；若集成不生效，先确认 Codex 已完全重启。
④ 手动修改 config.toml 后需重启 Codex 才能生效。

hook 超时

全局统一（不是按 agent 分别配置），对所有 agent 的 3 条 hook 生效。过短会在高负载下被宿主静默杀死（默认 10 秒）。保存后自动重写所有已检测 agent 的 hooks 配置。

强制检查方式

仅对 Reasonix 生效（sidecar 每条输入实时读取，改动即时生效）。auto 自省 = 经验沉淀提醒；changelog = 改了代码未更新日志的检查。
